# Landing image

`dallas-after-hours.png` was AI-generated for this project on October 17, 2026. It is an illustrative evening rooftop scene inspired by Dallas, not a photograph of a particular venue or an actual group outing. The app labels it accordingly. It is stored locally so the landing page works without a third-party image host.

Only actual user-uploaded images belong in the scrapbook. Uploads are stored under the ignored `data/photos/` directory, never in this assets directory.
